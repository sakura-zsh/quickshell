# 2026-09-13

## 任务栏从左改到顶部（完整横向化重构，sakura 选定方案）

**成果**：`modules/bar/` 由竖向架构改为顶部横向，提交 `e87bce6`（重构前快照 `a977298` 可回滚）。

**根因**：原 bar 是硬编码竖向架构，不是配置项。竖向假设分布在 20 个文件：
- `BarWrapper.qml`：`implicitWidth` + `anchors.right` + states 动画宽度
- `Bar.qml`：根 `ColumnLayout`、spacer `Layout.fillHeight`、`childAt(width/2, y)`/`checkPopout(y)`/`handleWheel(y)` 全按 y 轴
- `ActiveWindow.qml`：`Rotation { angle: 90/270 }` —— 就是"标题躺着放"的根因
- `Clock.qml`：`implicitWidth: innerWidth` + 时间格式 `"hh\nmm"` 竖排
- `drawers/`：`Drawers.qml` mask/regions、`Exclusions/Border/Backgrounds/Panels/Interactions` 共 8 处 `bar.implicitWidth` 定位

**改造方法**：
- 保留 `Config.bar.sizes.innerWidth` 字段名，横向后作为 bar 的**厚度（高度）**使用，避免用户配置迁移
- 轴向翻转对照：`implicitWidth↔implicitHeight`、`ColumnLayout↔RowLayout`、`fillHeight↔fillWidth`、`topMargin↔leftMargin`、`childAt(width/2,y)↔childAt(x,height/2)`、`anchors.left/right↔anchors.top/bottom`
- drawers 定位偏移：水平偏移由 `bar.implicitWidth` 改为 `Config.border.thickness`，垂直偏移由 `Config.border.thickness` 改为 `bar.implicitHeight`
- `Panels.qml` 的 popouts 定位：`y` 跟随 `currentCenter` 改为 `x` 跟随，`y` 固定贴顶

## ⚠️ 排查陷阱（重要）

1. **bar 改完后完全消失，一度误判为布局 bug** —— 实际是 **quickshell 进程已崩溃**（热重载大改动 + 反复 reload 后实例挂掉）。判断方法：`pgrep -x quickshell` 无输出即为进程不存在，而非代码问题。
2. **热重载对这种量级的改动不可靠**：多次 reload 后会出现"Configuration Loaded 但组件不实例化"的状态。改完应**重启实例**：`pkill -x quickshell; setsid quickshell -c /home/sakura/.config/quickshell > /tmp/qs.log 2>&1 &`
3. **全屏窗口会遮挡 layer-shell top 层**：niri 中窗口全屏时 bar 不可见（截图验证时容易误判为 bar 没渲染），验证前需退出全屏。
4. 调试手段：`quickshell log -t N` 读日志；`quickshell ipc call drawers toggle dashboard` / `quicktoggles open` 可在无鼠标模拟的情况下验证面板定位（`xdotool` 在 Wayland 下无效，`ydotool`/`wtype` 未安装）。

## popout 与 bar 连接修复（20:50 追加）

- 用户反馈：托盘/右侧按钮 popout 与 bar 连接不自然，且关闭后白背景残留。
- 残留根因：Wrapper.qml 的 nonAnimWidth 条件 `x > 0 || hasCurrent` 是左侧 bar 时代逻辑（贴 bar 时 x==0）；横向化后 x 恒为居中位置 >0，关闭时宽度永不收敛，Shape 融合背景不消失。
- 修复：Background.qml 顶部直角融合；Wrapper 改为高度收合（implicitHeight: open ? H : 0 + Behavior），宽度直接设定；Content Loader 锚点镜像为 bottom+horizontalCenter。
- 验证方法：Panels.qml 临时加 Timer 强制 popouts.hasCurrent=true + 自动 close，grim 截图对比开/关两态，再移除 Timer 冷重启。
