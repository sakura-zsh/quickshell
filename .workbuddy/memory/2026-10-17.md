# 2026-10-17 工作日志

## 共享壁纸（所有工作区一张壁纸，总览不再出现黑底）

需求（sakura）：现在的壁纸是"每个工作区一张"，`Mod+O` 进 niri 总览后每个工作区各带一份壁纸、间隙是黑的；他在 noctalia 下习惯的是"只有一张壁纸，动的只有窗口"。要后者。

关键事实（已核实，niri 26.04）：

- workspace 内容（含 Background 层里"归属该工作区"的 layer surface）会被合成器跟着工作区一起平移缩放：总览里 niri 会把它内缩成一圈"边框"、窗口叠在它上面。所以**只要 surface 还在 background 层且属于某工作区，就一定会动**，纯 QML 无法让它静止。
- 只有 `--json outputs` / `layout` 里有 2D 布局；workspace 层面没有任何位置字段。
- 事件流里有 `Overview opened or closed`；请求 `"OverviewState"` 返回 `{"Ok":{"OverviewState":{"is_open":bool}}}`；`"WorkspacePositions"` 请求**不存在**（`error parsing request`）。若将来 niri 加了 `WorkspacePositionsChanged`，插件已会解 `positions[].{output,workspace_id,view_offset.x}`。

改动：

- `config/BackgroundConfig.qml`：新增 `sharedWallpaper: true`、`sharedWallpaperPad: 20`；`Config.serializeBackground()` 同步。
- `modules/background/SharedWallpaper.qml`（新）：`PanelWindow` 常驻（namespace `caelestia-shared-wallpaper`），按屏幕列出该输出的所有工作区列；列 = 整屏壁纸切片，`x` 取 `Niri.workspacePositions[id].view_offset`，拿不到位置时"停泊"到屏幕左侧 3 屏外；焦点工作区整屏、其余按 `pad` 内缩成圆角框。视频壁纸取静帧（`Wallpapers.getColorSource`）。
- `modules/background/Background.qml`：`shared` 为真时不挂 `Wallpaper` / `Visualiser` / 桌面时钟（它们必须绑在会移动的 surface 上），只保留纯色底；尾部用 `Variants{ SharedWallpaper{} }` 常驻（`SurfaceLayer` 的 surface 销毁会从层里消失，不能让层序在两种模式间重新协商）。
- `plugin/src/Caelestia/Internal/niriipc.{hpp,cpp}`：新增 `workspaceViewOffsets` 属性 + `WorkspacePositionsChanged` 处理 + 启动时拉 `OverviewState`（`inOverview` 之前只在事件里更新）。
- `services/Niri.qml`：暴露 `workspacePositions`。**不要**在 Niri.qml 里加名为 `focusWorkspace` 的函数（与 `NiriIpc::action` 重名会冲突）。
- `AppearancePane.qml` + `sections/BackgroundSection.qml`：「所有工作区共用一张壁纸」开关 + 「总览中工作区留边」滑块（0–80px）。

验证：qmllint（带 qmldir 的 lint 树）无新错误；PySide6 offscreen 桩化跑真实 `SharedWallpaper.qml`（`verify/gen_wallpaper.py` + `run_wallpaper.py` + `wallpaper_t.qml`）：总览开 → 三列分别在 -2600/0/+2730、非焦点列内缩 20px 圆角 10、焦点列整屏；丢位置 → 全部停泊且不可见；关模式 → `visible` 全 false。
插件已 `cmake --build build --target caelestia-internal` 编好（`build/plugin/src/Caelestia/Internal/libcaelestia-internal.so`），**需按项目记录的方式装到 `/usr/lib/qt6/qml/Caelestia/Internal/`**。

待用户确认的取舍（已经告诉他）：没有位置事件时，非焦点列一律"框"形态——比旧行为（黑底）好，但总览里不会看到各工作区完整壁纸彼此拼接。
