
## bar 布局重排：窗口标题移到左侧、时钟移到中间（09-23）

- 需求：activeWindow 从中间挪到 workspaces 右侧；clock 从右侧挪到中间。
- 实现：只改 shell.json 的 bar.entries 顺序 —— logo, workspaces, activeWindow, spacer, clock, spacer, tray, divider, statusIcons, divider, power, idleInhibitor。
- 配套代码改动：新增 Config.bar.activeWindow.maxWidth（默认 0 = 原行为），用户配置设为 360。原因：ActiveWindow.maxWidth 原本 = bar.width - 其他模块宽度 - 间距 - 内边距，且计算时把 spacer 排除在"其他模块"之外，等于可吃光 spacer 的空间；标题长时会挤掉 spacer，把居中的 clock 顶偏。
- 分隔线变化：原 [tray] | [clock statusIcons] | [power] 变为 [tray] | [statusIcons] | [power]（clock 移出该组到中央）。
- 未验证：本轮命令环境无法访问用户会话（niri/quickshell 不可见、grim "failed to create display"，沙箱内外皆然），截图与热重载验证未完成，待用户目视确认。

## bar 三项改进：统一背景色 / 时钟秒数 / 居中补偿（09-23 第二轮）

- 需求：① 窗口标题与托盘加背景色且与时钟一致 ② 时钟偏右需修正 ③ 时钟显示秒数。
- 背景色统一令牌：Colours.tPalette.m3surfaceContainer（clock/tray/status/workspaces 全用这个）。ActiveWindow 本次新增 background 选项并改用 StyledRect 根，内边距用 padding.md(=10)，与 clock/tray 开启背景后的内边距一致。
- 秒数：Clock 新增 showSeconds，格式 hh:mm:ss（12 小时制 hh:mm:ss A）；Time.format 走 Qt.formatDateTime，SystemClock 精度已是 Seconds，等宽字体保证宽度不跳。
- 居中根因：两个 fill spacer 把中间模块放在"空闲区中心"，不是屏幕中心；偏移 = (左组宽 - 右组宽)/2。修法：给较窄一侧的 spacer 加 Layout.preferredWidth = 两侧组宽差，使中间模块落到真中心。仅当恰好 2 个 enabled spacer 时生效，否则退回原行为。
- 未验证：本轮命令环境仍无法访问用户会话（niri/quickshell 不可见、grim failed to create display），截图与运行验证未完成。
- 遗留待定：logo（OsIcon）未加背景（用户只点名标题与托盘），如需要可再加。
