# 2026-09-09

## 内屏 eDP-1/eDP-2 交替问题（已修复）

- 根因：双显卡笔记本（AMD Raphael 核显 card2 + NVIDIA RTX 4070 card1），16 寸便携内屏在两块 GPU 的连接器间交替枚举——AMD 侧叫 eDP-1，NVIDIA 侧叫 eDP-2，随开机驱动加载顺序轮换。`niri msg output off` 是临时配置重启即失效，故每次开机都要手动关。
- 修复：`~/.config/niri/cfg/display.kdl` 删除了重复的两个 `output "eDP-1"` 块（一个设 240Hz 模式一个 off，互相冲突），改为 `output "eDP-1" { off }` + `output "eDP-2" { off }` 持久化关闭；注释里保留了启用时的推荐配置（2560x1600@239.998, scale 1.25）。`niri validate` 通过。
- 机器连接器拓扑：`card1-eDP-2`（NVIDIA）、`card2-eDP-1`（AMD），外接屏 HDMI-A-1 挂在 NVIDIA card1，niri config 用输出描述字符串 "PNP(SAC) G52plus 0000000000000" 指定 144Hz。

## DisplayPane 排版压缩问题（已修复）

- 症状：面板内容被压成 ~50px 竖条（Flickable contentItem 宽度未传导到 ColumnLayout）。
- 修复：`modules/controlcenter/display/DisplayPane.qml` 中布局 ColumnLayout 由 `anchors.left/right: parent` 改为 `width: flick.width`（Flickable 内部布局宽度用 id 显式绑定）。
- 验证手段（可复用）：临时 PanelWindow 测试实例 + `quickshell -p <file>` + grim 截图；Wayland 普通窗口无法置顶/自定位，layer-shell overlay（exclusiveZone: -1）可保证可见。注意 `quickshell -p` 加载配置根外文件时 qs.* 模块不解析，测试文件必须放在配置根目录并加 `//@ pragma Env QML2_IMPORT_PATH=/home/sakura/.config/quickshell`（Caelestia 插件依赖此路径）。
- 测试文件 test-display-pane.qml 已删除。
