
## dashboard 触发区收窄（09-15）

- 需求：dashboard 鼠标触发从"bar 中部下方"移到"bar 上方"，避免鼠标横向移动误触。
- 根因：Interactions.qml inTopPanel 的 y 条件为 y < barHeight + panel.y + panel.height，等于「屏幕顶端 → dashboard 底边」全高命中，bar 下方整片区域都算触发区（窗口标题栏正好在其中）。
- 改法：inDashboardTrigger 限定 y < bar.implicitHeight（仅 bar 条带）；inDashboardOpenArea 保证已打开时鼠标进入面板内部不被收起；拖拽与快捷键判定同步收窄；删除无引用的 inTopPanel。

## 召唤区移到屏幕顶部窄带（09-15 二次调整）

- 用户反馈：bar 条带整片仍易误触（越过 bar/dashboard 连接线就弹出）。
- 定案：召唤区 = 屏幕最顶部窄带（bar 上边界），高度由 Config.dashboard.hoverTriggerHeight 控制（默认 12px，下限 6px），且需落在 dashboard 水平范围内。
- 重要配套：保持区（inDashboardOpenArea）必须宽松（y < barHeight + panel.y + panel.height && 水平命中），否则光标从顶部条带向下穿过 bar 时会因经过"空隙"而提前收起。
- bar 几何：drawers 全屏窗口，BarWrapper 锚 top，故 bar 上边界 = 屏幕顶边 y=0。
